# Proyecto: Todo - Práctica

Estructura inicial del proyecto (MVC, JavaScript frontend).

Primero pasos

- Abrir `index.html` en el navegador para ver la aplicación.

Convenciones relevantes

- Patrón: MVC. Modelos en `src/models`, vistas en `src/views`, controladores en `src/controllers`.
- Una clase por archivo. Comentarios en español.
- Variables y funciones en camelCase. Documentar funciones públicas con JSDoc.

Desarrollo

- Archivo principal: `index.html` carga `src/controllers/TodoController.js` como módulo.

Si querés que agregue un `package.json` o configuraciones de bundler, decímelo y lo creo.
